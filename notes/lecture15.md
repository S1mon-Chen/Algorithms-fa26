## 1. 本讲研究什么？（第 2–4 页）

前面的课程已经介绍最短路、最小生成树、二分图匹配、最长递增子序列、最大流等问题的高效算法。本讲开始追问：

> 给定一个候选解时，我们很容易检查它是否合法；为什么找到这样的解可能困难得多？

### 1.1 搜索空间很大，不等于必须穷举

一个问题可能有指数多个候选解，但仍能用多项式时间求解。例如：

- 图中可能有指数多条简单路径，但非负权最短路可以用 Dijkstra 算法求解。
- 图中可能有大量生成树，但 MST 可以利用割性质逐步选择安全边。
- 一个序列有 $2^n$ 个下标子集，但最长递增子序列可以用动态规划求解。

因此，不能从“候选解有 $2^n$ 个”直接推出“任何算法都需要 $2^n$ 时间”。高效算法的作用，恰恰是利用结构绕过穷举。

### 1.2 “多项式”必须相对于输入长度

若运行时间为 $O(L^k)$，其中 $k$ 是与输入无关的常数，就称为**多项式时间**。这里的 $L$ 不是某个整数参数的数值，而是编码整个实例所需的长度。

例如，容量 $W=2^k$ 只需 $k+1$ 个二进制位表示。遍历 $0,1,\ldots,W$ 需要约 $2^k$ 步，不能因为复杂度写成 $O(W)$ 就说它是关于输入长度的多项式。

**辨析。** 多项式时间是理论上区分可高效求解问题的主要标准，不保证所有实际输入都很快；指数算法也可能适用于规模很小的实例。讲义第 4 页强调的是随规模增长的可扩展性。

### 1.3 本讲的几组对比

| 已有高效算法的问题 | 看似很小的改动 | 本讲引出的另一问题 |
| --- | --- | --- |
| 最小生成树 | 要求树不能分叉 | 经过所有顶点的最小权路径；进一步闭合得到 TSP 型要求 |
| 2-SAT | 每个子句允许三个文字 | 3-SAT |
| Euler 路径 | “每条边一次”改为“每个顶点一次” | Hamilton 路径／环 |
| 全局最小割 | 要求割的两侧都足够大 | 平衡割 |
| 线性规划 | 实数变量改为整数变量 | 整数线性规划 |
| 二分图匹配 | 两类对象改为三类对象 | 三维匹配 |
| 最短路 | 最小化改为最大化，并要求不重复顶点 | 最长简单路径 |
| 一元编码背包 | 数值改用紧凑的二进制编码 | 同一个 DP 不再给出多项式时间界 |

这些对比说明：**结构限制和输入表示都是问题定义的一部分，会影响算法的难度。** 本讲主要介绍问题和转换方式，并未逐个给出 NP 完全性证明；不能把“尚无高效算法”的讨论当成指数时间下界证明。

## 2. 从 MST 看“增加一个限制”的影响（第 5–8 页）

### 2.1 网络建设模型

将计算机看作顶点、可建设的连接看作无向边、维护费用看作边权。在连通图中，MST 要求找一棵连接全部顶点、总权重最小的生成树。

树允许分叉。某个顶点可以连接多个其他顶点，这一自由度对 MST 的贪心算法很重要。

### 2.2 讲义中的通用贪心框架

令 $X$ 表示已经选中的边，初始为空。反复选择一个与 $X$ 相容的割，并加入跨割的最轻边：

```text
GENERIC_MST(G):
    X = empty set
    while |X| < |V| - 1:
        choose a nonempty proper subset S of V
            such that no edge of X crosses (S, V \ S)
        e = a minimum-weight edge crossing (S, V \ S)
        X = X union {e}
    return X
```

这里假设输入图连通，因此任何非平凡割都有跨割边。“没有已选边跨割”意味着 $S$ 是当前森林若干连通分量的并。

**补充证明：安全边性质。** 维持不变式“存在一棵 MST 包含 $X$”。设这棵树为 $T$：

1. 若 $e\in T$，直接加入即可。
2. 若 $e\notin T$，在 $T$ 中加入 $e$ 会产生一个环。
3. 环上还有另一条跨越同一个割的边 $f$；由于 $X$ 没有跨割边，$f\notin X$。
4. $e$ 是最轻跨割边，所以 $w(e)\le w(f)$。用 $e$ 替换 $f$，得到包含 $X\cup\{e\}$、权重不增加的生成树，也必为 MST。

讲义称它为一般化的 Kruskal 算法；严格说，它是依赖割性质的通用安全边框架，具体如何选割、维护最轻边，决定实现和运行时间。

**例题演算。** 第 6 页的网络中，一棵 MST 可取

$$
\{AC,CD,AB,CF,EF\},\qquad
w=1+2+4+4+5=16.
$$

按 Kruskal 顺序，$AC,CD$ 先加入；$AD$ 虽然权重为 3，却会形成环，不能加入。连接 $B$ 时，$AB,BC,BD$ 的权重都为 4，可以任选其中一条。

### 2.3 如果树不能分叉？

在至少有两个顶点的树中，要求所有顶点度数不超过 2，就迫使整棵树成为一条经过全部顶点的简单路径，也就是 **Hamilton 路径**。

MST 的安全边交换只保证“仍然是一棵生成树”，不会保证“每个顶点度数不超过 2”。加入额外限制后，原证明失效，不能直接沿用贪心算法。

**辨析。** “不分叉的生成树”是开放路径；TSP 要求最后回到起点，是环。第 8、25 页是在强调结构上的联系，两者不是完全相同的问题定义。

## 3. SAT：容易验证的布尔搜索问题（第 9–10、15、19 页）

### 3.1 变量、文字、子句与 CNF

| 名称 | 含义 | 例子 |
| --- | --- | --- |
| 布尔变量（variable） | 取 $\mathrm{true}$ 或 $\mathrm{false}$ | $x$ |
| 文字（literal） | 一个变量或它的否定 | $x,\neg x$ |
| 子句（clause） | 若干文字的逻辑或 | $x\lor\neg y\lor z$ |
| 合取范式（CNF） | 若干子句的逻辑与 | $(x\lor y)\land(\neg x\lor z)$ |
| 满足赋值 | 使整个公式为真的变量赋值 | 每个子句至少有一个真文字 |

记

$$
\varphi=\bigwedge_{j=1}^{m}C_j.
$$

SAT 的搜索版本要求：给定 CNF 公式 $\varphi$，找出一个满足赋值；若不存在，则报告无解。

有 $n$ 个变量时，共有 $2^n$ 个完整赋值。若所有子句合计有 $q$ 次文字出现，检查一个给定赋值只需扫描这些文字，耗时 $O(n+q)$；朴素穷举则需要 $O(2^n(n+q))$ 时间。

### 3.2 讲义公式中的否定不能漏掉

第 10、15 页的公式是

$$
\varphi=(x\lor y\lor z)
\land(x\lor\neg y)
\land(y\lor\neg z)
\land(z\lor\neg x)
\land(\neg x\lor\neg y\lor\neg z).
$$

PDF 中否定使用上划线，纯文本提取容易丢失；这里统一写成 $\neg$。

**例题演算。** 这个公式不可满足：

- $x\lor\neg y$ 表示 $y\Rightarrow x$。
- $y\lor\neg z$ 表示 $z\Rightarrow y$。
- $z\lor\neg x$ 表示 $x\Rightarrow z$。

三者形成 $x\Rightarrow z\Rightarrow y\Rightarrow x$，所以任何一个变量为真，另外两个也必须为真。第一个子句要求至少一个为真，于是只能全真；但最后一个子句在全真时为假，产生矛盾。

### 3.3 检查一个赋值，与证明无解不同

若有人给出一个赋值，我们可以迅速判断它是否满足公式。但若这个赋值失败，只能说明**这个候选解不合法**，不能说明其他 $2^n-1$ 个赋值都失败。

这就是本讲反复使用的区分：

$$
\boxed{\text{容易验证一个解}\quad\text{不直接推出}\quad\text{容易找到解或证明无解}.}
$$

## 4. 2-SAT：用强连通分量代替枚举（第 11–13 页）

### 4.1 从子句到蕴含图

2-SAT 要求每个子句至多有两个文字。一个单位子句 $(\alpha)$ 可以写成 $(\alpha\lor\alpha)$；若出现空子句，则直接不可满足。

关键等价式为

$$
\boxed{
(\alpha\lor\beta)
\iff(\neg\alpha\Rightarrow\beta)
\land(\neg\beta\Rightarrow\alpha).
}
$$

因此构造**蕴含图（implication graph）**：

- 每个变量 $x_i$ 对应两个顶点 $x_i,\neg x_i$。
- 每个子句 $(\alpha\lor\beta)$ 加入两条有向边

$$
\boxed{\neg\alpha\to\beta,\qquad\neg\beta\to\alpha.}
$$

图有 $2n$ 个顶点、至多 $2m$ 条不同的边；保留重复边时，边记录数为 $2m$。一条路径 $a\leadsto b$ 表示：任何满足赋值只要令 $a$ 为真，就必须令 $b$ 为真。

特别地，每条边 $a\to b$ 都有配对边 $\neg b\to\neg a$。对路径反向并逐个取否定，也得到

$$
a\leadsto b\quad\Longrightarrow\quad\neg b\leadsto\neg a.
$$

### 4.2 可满足性的充要条件

记 $\operatorname{comp}(a)$ 为文字 $a$ 所在的强连通分量。则

$$
\boxed{
\varphi\text{ 可满足}
\iff
\forall i,\quad
\operatorname{comp}(x_i)\ne\operatorname{comp}(\neg x_i).
}
$$

**必要性。** 若 $x_i$ 与 $\neg x_i$ 在同一 SCC 中，就同时存在

$$
x_i\leadsto\neg x_i,\qquad
\neg x_i\leadsto x_i.
$$

令 $x_i$ 为真，会推出 $\neg x_i$ 为真；令 $x_i$ 为假，则 $\neg x_i$ 为真，又推出 $x_i$ 为真。两种取值都矛盾。

**易错点。** 只有 $x\leadsto\neg x$ 并不足以证明不可满足，它只说明任何满足赋值都必须令 $x$ 为假。真正的矛盾是两个方向都可达。

### 4.3 如何构造赋值？（补充证明）

把 SCC 缩成一个 DAG。按**从源到汇**的拓扑顺序编号，记分量编号为 $r(C)$，不同分量之间若有边 $C\to D$，就有 $r(C)<r(D)$。

为了简化记号，写 $r(a)=r(\operatorname{comp}(a))$。在同一分量中的文字编号相同。若没有变量与其否定同分量，定义

$$
\boxed{x_i=\mathrm{true}\iff r(x_i)>r(\neg x_i).}
$$

即一对互为否定的分量中，拓扑位置较靠后的那个取真。由于每对编号不同，每个变量恰好获得一种取值。

下面证明不存在“真文字指向假文字”的边。假设 $a\to b$，但 $a$ 真、$b$ 假，则

$$
r(\neg a)<r(a),\qquad r(b)<r(\neg b).
$$

由 $a\to b$ 及配对边 $\neg b\to\neg a$，有

$$
r(a)\le r(b),\qquad r(\neg b)\le r(\neg a).
$$

合并得

$$
r(\neg a)<r(a)\le r(b)<r(\neg b)\le r(\neg a),
$$

矛盾。因此所有蕴含边都成立。若某个子句 $(\alpha\lor\beta)$ 为假，则 $\neg\alpha$ 真而 $\beta$ 假，违反边 $\neg\alpha\to\beta$；所以所有子句都为真，充分性得证。

**实现说明。** SCC 算法返回的编号未必按上述方向排序。不能不检查编号含义，就照抄 `comp[x] > comp[not x]`；可以显式构造缩点图并拓扑排序。

### 4.4 算法与复杂度

```text
TWO_SAT(clauses, variables):
    if an empty clause exists:
        return UNSAT

    build the implication graph G
    compute all strongly connected components of G

    for each variable x:
        if comp[x] == comp[not x]:
            return UNSAT

    build the condensation DAG
    rank its components in source-to-sink topological order

    for each variable x:
        value[x] = (rank[comp[x]] > rank[comp[not x]])
    return value
```

利用 [Lecture 6](lecture6.md) 的 SCC 与拓扑排序算法，每一步均为线性时间，因此

$$
\boxed{T_{\text{2-SAT}}=O(n+m),\qquad\text{空间}=O(n+m).}
$$

这里采用通常的图算法计数模型，将变量编号、邻接表访问视为常数时间操作。

### 4.5 讲义中的 2-SAT 例子

第 11 页给出

$$
(x_1\lor x_2)
\land(\neg x_1\lor x_3)
\land(x_1\lor\neg x_2)
\land(x_3\lor x_4)
\land(\neg x_1\lor\neg x_4).
$$

| 子句 | 两条蕴含边 |
| --- | --- |
| $x_1\lor x_2$ | $\neg x_1\to x_2$，$\neg x_2\to x_1$ |
| $\neg x_1\lor x_3$ | $x_1\to x_3$，$\neg x_3\to\neg x_1$ |
| $x_1\lor\neg x_2$ | $\neg x_1\to\neg x_2$，$x_2\to x_1$ |
| $x_3\lor x_4$ | $\neg x_3\to x_4$，$\neg x_4\to x_3$ |
| $\neg x_1\lor\neg x_4$ | $x_1\to\neg x_4$，$x_4\to\neg x_1$ |

**例题演算。** 一个从前到后的拓扑顺序是

$$
\neg x_3,\ x_4,\ \neg x_1,\ x_2,\ \neg x_2,\ x_1,\ \neg x_4,\ x_3.
$$

按照第 4.3 节的规则，可得

$$
(x_1,x_2,x_3,x_4)=(\mathrm{true},\mathrm{false},\mathrm{true},\mathrm{false}).
$$

事实上，$x_1$ 必须为真，否则第一、第三个子句分别要求 $x_2$ 真和假；继而 $x_3$ 必须为真、$x_4$ 必须为假，而 $x_2$ 可以任选。

### 4.6 从 2-SAT 到 3-SAT（第 13 页）

若每个子句至多包含三个文字，就得到 3-SAT；一般 CNF-SAT 不限制子句长度。

子句 $(a\lor b\lor c)$ 表示的是：当 $a,b$ 都为假时，$c$ 必须为真，即

$$
(\neg a\land\neg b)\Rightarrow c.
$$

这里的前提需要两个文字同时成立，不能直接作为普通蕴含图中“一条文字到另一条文字”的边。若擅自加入 $\neg a\to c$，就把条件加强了，可能排除原本合法的赋值，例如 $a=\mathrm{false},b=\mathrm{true},c=\mathrm{false}$。

因此，2-SAT 的 SCC 方法不能直接推广到 3-SAT。这个观察解释了原算法为何失效；它不等于证明不存在其他高效算法。

### 4.7 另一类可解公式：Horn-SAT（第 19 页，补充解释）

**Horn 子句**至多包含一个正文字。例如

$$
\neg a\lor\neg b\lor c
\iff(a\land b)\Rightarrow c.
$$

没有正文字的子句可以理解为禁止条件：

$$
\neg a\lor\neg b
\iff(a\land b)\Rightarrow\mathrm{false}.
$$

求解思路是从所有变量为假出发，反复执行被触发的规则：

1. 若一条规则的所有前提都为真，就把结论变量设为真；单位正子句相当于没有前提的规则。
2. 若某个禁止条件的前提全部为真，则报告不可满足。
3. 若没有新变量被迫为真，且没有触发禁止条件，当前赋值就是满足赋值。

正确性的关键是：每个被置真的变量，在任何满足赋值中都必须为真，可以按推导顺序归纳。因而触发禁止条件时，所有可能的满足赋值都会冲突。

用计数器记录每条规则尚未满足的前提数，配合出现列表和队列，可在关于变量数与文字总出现次数的线性时间内完成。Horn-SAT 可以有很长的子句；它的可解结构是“正文字至多一个”，与 2-SAT 的“总文字数至多两个”不同。

## 5. 判定、搜索与验证（第 14–18 页）

### 5.1 三件事分别在做什么？

| 任务 | 输入 | 输出 |
| --- | --- | --- |
| 判定（decision） | 实例 $I$ | 是否存在合法解：YES／NO |
| 搜索（search） | 实例 $I$ | 一个合法解 $S$，或报告不存在 |
| 验证（verification） | 实例 $I$ 和候选解 $S$ | 判断这个 $S$ 是否满足要求 |

对 SAT 而言，判定回答“有没有满足赋值”，搜索输出具体赋值，验证检查已经给出的赋值。

完整的搜索算法必须能在无解时正确报告无解。一个只会尝试若干赋值、失败后返回“不知道”的过程，不能代替这里的搜索算法。

### 5.2 搜索算法可以解决判定问题

调用搜索算法：若得到解则回答 YES；若报告无解则回答 NO。这个方向只需要一次调用。

### 5.3 SAT 的判定算法也能恢复一个解

**补充证明：自归约（self-reduction）。** 假设有一个黑盒 `SAT_DECIDE(F)`，能正确回答公式 $F$ 是否可满足。

先判断原公式是否可满足。若可满足，就依次固定变量：尝试把 $x_i$ 设为假，并询问剩余公式是否仍可满足。

```text
SAT_SEARCH(F):
    if SAT_DECIDE(F) == NO:
        return UNSAT

    for each original variable x_i:
        F0 = simplify F after substituting x_i = false
        if SAT_DECIDE(F0) == YES:
            assignment[x_i] = false
            F = F0
        else:
            assignment[x_i] = true
            F = simplify F after substituting x_i = true

    return assignment
```

每一轮开始时，当前 $F$ 都可满足。因此，若 $x_i=\mathrm{false}$ 分支不可满足，$x_i=\mathrm{true}$ 分支必然可满足。这个不变式保证最后得到的完整赋值满足原公式。

代入变量时，删除已满足的子句，删除剩余子句中取假的文字；出现空子句表示矛盾，所有子句都被删除则表示剩余变量可以任意赋值。

若原输入长度为 $L$，黑盒耗时为 $T(L)$，则只需至多 $n+1$ 次调用，且代入不会增大公式：

$$
\boxed{T_{\text{search}}=O\bigl((n+1)T(L)+nL\bigr).}
$$

所以 SAT 的判定与搜索版本在多项式时间可解性上等价。这里使用的是允许多次、自适应调用黑盒的**多项式时间 Turing 归约**。

**讲义辨析。** 第 17 页把判定与搜索概括为相互归约，但不能把它理解为“任意搜索问题都自动与其存在性判定等价”，也不能把判定机器的输出当作现成解：判定机器只承诺输出 YES／NO。SAT 的反向转换依赖上面明确的自归约结构。

### 5.4 用检查器描述搜索问题

第 18 页将搜索问题写成检查算法 $C(I,S)$：

$$
\boxed{S\text{ 是 }I\text{ 的合法解}\iff C(I,S)=\mathrm{true}.}
$$

检查器应当在关于实例长度的多项式时间内完成。

**补充：解的长度也要受控制。** 在与 NP 对应的标准表述中，还要求存在多项式 $p$，使证书长度满足 $|S|\le p(|I|)$。否则，一个过长的候选解连完整读入都可能无法在多项式时间内完成。

这样的判定问题可以写成

$$
I\text{ 为 YES 实例}
\iff
\exists S,\quad |S|\le p(|I|)\ \land\ C(I,S)=\mathrm{true}.
$$

**术语预告（补充）。** P 指可在确定性多项式时间内判定的问题；NP 指 YES 实例具有多项式长度、可在确定性多项式时间内验证的证书的问题。NP 的名称来自 nondeterministic polynomial time，**不是 non-polynomial**。有 $\mathrm{P}\subseteq\mathrm{NP}$，所以“属于 NP”本身不表示这个问题难解。

SAT 的证书是一个赋值；“这个公式无解”不能通过随便展示一个失败赋值来验证。NP 的上述证书要求针对 YES 实例，而不是同时要求 NO 实例也有同类证书。

## 6. TSP：搜索与优化如何转换？（第 20–25 页）

### 6.1 问题定义

给定 $n$ 个城市、每对城市间的距离或费用 $d_{ij}$，以及预算 $b$。讲义采用无向完全图，因此给出 $n(n-1)/2$ 个距离；以下按通常的 $n\ge3$ 情形讨论。

需要找一个城市排列 $\tau(1),\ldots,\tau(n)$，每个城市恰好出现一次，并且

$$
\boxed{
\sum_{i=1}^{n-1}d_{\tau(i),\tau(i+1)}
+d_{\tau(n),\tau(1)}\le b.
}
$$

最后一项表示回到起点，不能漏掉。一个巡回路线以相同顶点开始和结束是闭合所必需的；“恰好一次”指这之外不重复访问城市。

讲义的定义没有额外假设三角不等式，因此不要自动把它当成度量 TSP。

### 6.2 同一个问题的三个版本

| 版本 | 要求 |
| --- | --- |
| 判定 | 是否存在总费用不超过 $b$ 的巡回路线？ |
| 搜索 | 给出一条总费用不超过 $b$ 的巡回路线，或报告不存在 |
| 优化 | 给出总费用最小的巡回路线 |

一个给定排列是否满足搜索要求很容易检查：

1. 检查是否包含全部城市且没有重复。
2. 累加 $n$ 条边，包括最后返回起点的边。
3. 比较总费用与预算 $b$。

若数值采用有限位编码，这些操作都能在输入长度的多项式时间内完成；算术操作的位数也应计入。

### 6.3 优化算法解决搜索问题

先求最优路线，设费用为 $\mathrm{OPT}$：

- 若 $\mathrm{OPT}\le b$，返回该路线。
- 若 $\mathrm{OPT}>b$，任何路线都超预算，报告无解。

只需一次优化调用。

### 6.4 搜索算法通过二分解决优化问题

**补充条件。** 先假设所有边权是非负整数，并令

$$
D=\max_{i<j}d_{ij}.
$$

因为完全图中存在巡回路线，并且路线包含 $n$ 条边，

$$
0\le\mathrm{OPT}\le nD.
$$

对一个预算 $b$，调用搜索算法，是否返回路线就是可行性判断。这个判断具有单调性：

$$
\text{存在费用}\le b\text{ 的路线}
\Longrightarrow
\text{存在费用}\le b'\text{ 的路线}\quad(b'\ge b).
$$

因此可以在整数区间 $[0,nD]$ 上二分，找到第一个可行预算：

```text
TSP_OPTIMIZE(distances):
    low = 0
    high = n * maximum_edge_cost

    while low < high:
        mid = floor((low + high) / 2)
        result = TSP_SEARCH(distances, budget=mid)
        if result is a tour:
            high = mid
        else:
            low = mid + 1

    return TSP_SEARCH(distances, budget=low)
```

最终 `low` 等于最优费用。最后一次调用返回一条费用不超过最优值的路线，它只能是最优路线。

调用次数为

$$
\boxed{O\bigl(1+\log(nD+1)\bigr).}
$$

虽然 $D$ 的数值可能很大，但 $1+\log(D+1)$ 与其二进制编码长度同阶，所以调用次数仍然是输入长度的多项式。

若边权是二进制编码的有理数，可以通过公分母缩放为整数；分母乘积的位数不超过各分母位数之和，因此这种处理仍有多项式长度界。若把边权视为没有精度约定的任意实数，就不能直接声称“有限次普通二分一定得到精确最优值”。

**辨析。** 这里最后一次调用使用的是能返回路线的**搜索黑盒**。如果只有 YES／NO 判定黑盒，二分直接得到的是最优值；还原路线仍需额外的构造过程。

### 6.5 为什么不直接把“最优”作为可验证条件？

“这条路线费用不超过 $b$”只需要检查它自己；“这条路线最优”还要求排除所有更短路线。

所以“寻找最优解”虽然在日常语言中也叫搜索，却不能仅凭这个名称，就满足第 5 节对多项式时间检查器的要求。最优性是否有易验证的证书，需要单独论证。

对照 [Lecture 14](lecture14.md)：最大流可以用一个同值的割证明最优。这个证书来自最大流最小割定理，不能自动推广到所有优化问题。

### 6.6 指数算法也有优劣之分

直接枚举城市排列需要阶乘级别的搜索。[Lecture 11](lecture11.md) 的集合动态规划记录“已经访问的城市集合 + 当前终点”，将 TSP 求解时间降到

$$
O(n^2 2^n).
$$

这是很大的改进，但仍不是多项式时间。本讲借 TSP 强调：有动态规划算法，不代表状态总数一定是多项式。

## 7. Euler 与 Rudrata／Hamilton（第 26–30 页）

### 7.1 Euler 路径：每条边恰好使用一次

**Euler 路径／欧拉迹**要求经过图中的每条边恰好一次，允许重复访问顶点。讲义称为 path；严格的图论术语通常用 trail，以区别不重复顶点的 simple path。

对至少有一条边的无向图，存在 Euler 迹的充要条件为：

1. 所有非孤立顶点处于同一个连通分量。
2. 奇数度顶点的数量为 0 或 2。

$$
\boxed{
\begin{array}{ll}
0\text{ 个奇度顶点}:&\text{存在 Euler 回路，起终点相同};\\
2\text{ 个奇度顶点}:&\text{存在开放 Euler 迹，起终点恰为这两个顶点}.
\end{array}
}
$$

**讲义补全。** 第 28 页直接写“图连通”；若允许孤立顶点，应改为“去掉孤立顶点后连通”，因为没有边的顶点不影响遍历每条边。无边图可按约定取平凡的零长度迹。

### 7.2 度数条件为什么成立？

**必要性。** 除起终点外，每次进入一个顶点都必须从另一条未使用边离开，因此使用的关联边成对出现，度数为偶数。开放迹的两个端点各有一条未配对的边，度数为奇数。

**充分性与算法思路（补充）。** 若所有度数为偶数，从任一非孤立顶点沿未使用边走，直到不能继续，所得路线会回到起点。若还有未使用边，由连通性可在已有回路上的某个顶点出发找到新的闭合路线，并将它拼入原回路。重复直到所有边用完，这就是 Hierholzer 算法的思想。

若有两个奇度顶点，可以先在它们之间加一条临时边，求 Euler 回路，再删除临时边，把回路打开成所需的迹。临时边允许成为平行边。

使用边编号、邻接表与栈，每条边只处理常数次，总时间为 $O(n+m)$。

### 7.3 Hamilton 环：每个顶点恰好访问一次

讲义中的 **Rudrata Cycle** 就是通常所说的 **Hamilton Cycle（哈密顿环）**：找一个访问所有顶点恰好一次、最后回到起点的环。

| 对比项 | Euler 迹／回路 | Hamilton 路径／环 |
| --- | --- | --- |
| 必须覆盖的对象 | 所有边 | 所有顶点 |
| 顶点能否重复 | 可以 | 除闭环的起终点重合外，不可以 |
| 边是否必须全部使用 | 是 | 否 |
| 本讲使用的求解结构 | 连通性、奇偶度数、回路拼接 | 不能套用 Euler 的度数判据 |

**补充例子。** 两个三角形只共享一个顶点 $v$。共享点度数为 4，其他顶点度数为 2，图连通，因此存在 Euler 回路。但不存在 Hamilton 环：要访问两侧全部顶点并闭合，必须重复经过连接两侧的唯一共享点 $v$。

反过来，完全图 $K_4$ 有 Hamilton 环，但四个顶点的度数都为 3，有四个奇度点，因此没有 Euler 迹。这两个问题不能互相混淆。

## 8. 最小割与平衡割（第 31–34 页）

### 8.1 无向全局最小割

给定无向图，选取非空真子集 $S\subset V$，记

$$
\delta(S)=\{\{u,v\}\in E:u\in S,\ v\notin S\}.
$$

删除这些跨割边，就将 $S$ 与 $V\setminus S$ 分开。全局最小割的值为

$$
\boxed{\lambda(G)=\min_{\varnothing\ne S\subsetneq V}|\delta(S)|.}
$$

搜索版本给定预算 $b$，要求找到跨割边数不超过 $b$ 的非平凡划分，或报告不存在。若原图不连通，存在跨割边数为 0 的划分。

这里没有预先指定 $s,t$，与 [Lecture 14](lecture14.md) 的固定源汇最小割有所区别。

### 8.2 为什么只需 $n-1$ 次最大流？

固定任意顶点 $s$，对每个 $t\ne s$ 求一个最小 $s$–$t$ 割，取其中最小者。

把每条无向边替换为两个方向相反、容量都为 1 的有向弧。对于任意划分，每条无向跨割边恰有一条弧从源点一侧指向另一侧，因此有向割容量等于无向跨割边数，不会重复计为 2。

**补充证明。** 令 $\lambda(s,t)$ 为最小 $s$–$t$ 割值：

1. 任意 $s$–$t$ 割都是一个全局割，所以对所有 $t\ne s$，有 $\lambda(G)\le\lambda(s,t)$。
2. 取一个全局最优割 $(A,B)$，令 $s\in A$。由于 $B$ 非空，可选 $t\in B$。
3. 该割也是一个 $s$–$t$ 割，所以 $\lambda(s,t)\le|\delta(A)|=\lambda(G)$。

因此

$$
\boxed{\lambda(G)=\min_{t\ne s}\lambda(s,t).}
$$

借助最大流最小割定理，只需 $n-1$ 次最大流计算，因此仍为多项式时间。用最大流结束后的残量可达集，还可以恢复实际的割。

### 8.3 平衡割增加了什么要求？

最小割可能只切下一个低度数顶点。若目标是把网络分为规模相近的两部分，这种割不一定有用。

讲义的 **Balanced Cut** 要求找到划分 $V=S\mathbin{\dot\cup}T$，满足

$$
\boxed{|S|,|T|\ge n/3,\qquad |\delta(S)|\le b.}
$$

因为集合大小为整数，这等价于两侧大小至少为 $\lceil n/3\rceil$；不要求严格各占一半，因而不能直接等同于最小二等分问题。

**补充例子。** 在 6 个顶点的星形图中，普通最小割只需切下一片叶子，割值为 1。但平衡割的两侧都至少有 2 个顶点。没有中心的那一侧至少含两片叶子，因此至少切断 2 条边；选择恰好两片叶子即可达到 2。

最大流最小割算法只优化跨割容量，不会自动保证两侧规模。给最小割再加一个“大小条件”，不能直接沿用原算法的最优性证明。

## 9. 从线性规划到整数线性规划（第 35–40 页）

### 9.1 LP 与 ILP 的区别在变量取值域

线性规划允许变量取实数，例如

$$
\max c^Tx\quad\text{s.t. }Ax\le b,\ x\ge0.
$$

整数线性规划（ILP）进一步要求

$$
\boxed{x\in\mathbb Z_{\ge0}^{n}.}
$$

把变量从实数改成整数，不会改变每条约束的线性形式，却会使可行点变成离散集合。

**补充例子。** $\max x$，约束 $2x\le3,x\ge0$，LP 最优值为 $3/2$，ILP 最优值为 1。甚至一个 LP 可以可行而对应 ILP 不可行：$2x=1,x\ge0$ 只有实数解 $x=1/2$，没有整数解。

因此，LP 松弛可以提供界，却不能一般性地通过简单取整得到合法或最优的整数解。[Lecture 14](lecture14.md) 中整数容量最大流的整数性属于特殊结构，不能推广到任意 LP。

### 9.2 把目标值要求写成一个约束

第 38 页给出的搜索版本是：给定 $A,b,c,g$，寻找非负整数向量 $x$，使

$$
Ax\le b,\qquad c^Tx\ge g.
$$

其中 $g$ 是最大化目标希望达到的下界。

**讲义修正。** 第 39 页右侧将 $\max(2x_1+5x_2)$ 转换成阈值条件时，写成了 $2x_1+5x_2\le g$。按照第 38 页定义和第 39 页下方文字，应为

$$
\boxed{2x_1+5x_2\ge g.}
$$

完整模型还应保留整数限制，不能只写 $x_1,x_2\ge0$。

### 9.3 为什么可以只定义 ILP 可行性问题？

因为目标阈值本身也是线性不等式：

$$
c^Tx\ge g\iff -c^Tx\le-g.
$$

将它作为新的一行加入原约束：

$$
A'=\begin{bmatrix}A\\-c^T\end{bmatrix},\qquad
b'=\begin{bmatrix}b\\-g\end{bmatrix}.
$$

于是可以统一表述为

$$
\boxed{\text{给定 }A',b',\text{ 找 }x\in\mathbb Z_{\ge0}^{n}\text{ 使 }A'x\le b'.}
$$

这就是第 40 页采用的 ILP 搜索问题定义。

**辨析。** 讲义所谓“冗余”指的是无需把目标阈值单独列为一种输入形式；它可以并入矩阵。不是说可以直接删掉 $c^Tx\ge g$ 而不改变问题。

### 9.4 验证时要计算整数的位数

给定一个整数向量 $x$，检查非负性、整数性和全部线性不等式，在系数与 $x$ 的总编码长度上是多项式时间。

若要进一步将一般 ILP 严格放入第 5.4 节的证书框架，还需说明有解实例具有多项式位数长度的整数解，不能仅凭“只有 $n$ 个分量”就忽略每个分量可能很大。本讲在这里主要完成问题定义与阈值建模。

## 10. 二分图匹配与三维匹配（第 41–44 页）

### 10.1 二分图匹配回顾

二分图匹配从两类对象之间的兼容关系中选择若干条边，要求每个对象最多出现一次。

第 42–43 页回顾了最大流归约：

$$
s\to\text{左侧顶点}\to\text{右侧顶点}\to t,
$$

所有边容量均为 1。整数最大流中的每条单位流路径对应一对匹配；容量约束保证同一个对象不会被重复使用。

### 10.2 3D Matching 的定义

有三组两两不交的对象 $B,G,P$，各有 $n$ 个元素。讲义用男孩、女孩、宠物作例子。允许的组合由显式给出的三元组集合

$$
\mathcal T\subseteq B\times G\times P
$$

表示。一个 $(b,g,p)\in\mathcal T$ 表示三者可以共同组成一个家庭。

目标是找出

$$
\boxed{
M\subseteq\mathcal T,\qquad |M|=n,
\qquad M\text{ 中的三元组在每个坐标上都互不重复}.
}
$$

因为三类各有 $n$ 个对象，选到 $n$ 个互不相交三元组，就恰好覆盖每个对象一次。这是讲义采用的完美三维匹配版本。

“三元组互不相交”比“三元组互不相同”强得多。例如 $(b_1,g_1,p_1)$ 和 $(b_1,g_2,p_2)$ 虽然不同，却共享 $b_1$，不能同时选入匹配。

### 10.3 为什么不能直接再加一层流网络？（补充）

假设允许三元组中包含

$$
(b_1,g_1,p_1),\qquad(b_2,g_1,p_2).
$$

若只保留男孩到女孩、女孩到宠物的两两边，则网络会包含 $b_1\to g_1$ 和 $g_1\to p_2$，从而允许路径

$$
b_1\to g_1\to p_2.
$$

但 $(b_1,g_1,p_2)$ 未必在原来的 $\mathcal T$ 中。问题在于把三元关系拆成两种二元关系时，丢失了“这三者必须来自同一个允许三元组”的信息。

这说明**这种直接分层建图方式不正确**；它本身不是三维匹配困难性的完整证明。

### 10.4 合法解依然容易检查

给出 $n$ 个候选三元组后，只需验证它们都属于 $\mathcal T$，并且三类对象中没有任何元素出现两次。这里的输入规模还包括 $|\mathcal T|$，不能只用每类对象数 $n$ 衡量。

## 11. 独立集、顶点覆盖与团（第 45–46 页）

### 11.1 三个定义

对简单无向图 $G=(V,E)$：

| 问题 | 给定阈值 | 要寻找的顶点集合 |
| --- | --- | --- |
| 独立集（Independent Set） | 目标 $g$ | $S\subseteq V$，$\lvert S\rvert\ge g$，内部任意两点之间无边 |
| 顶点覆盖（Vertex Cover） | 预算 $b$ | $C\subseteq V$，$\lvert C\rvert\le b$，每条边至少有一个端点在 $C$ 中 |
| 团（Clique） | 目标 $g$ | $K\subseteq V$，$\lvert K\rvert\ge g$，内部任意两个不同顶点之间都有边 |

讲义写的是“找 $g$ 个／$b$ 个顶点”。对独立集和团，可以从更大的合法集合中删点；对顶点覆盖，可以向合法覆盖中加点。因此，在 $0\le g,b\le n$ 的正常参数范围内，存在性上与表中的阈值版本等价。

**易错点。** 顶点覆盖要求覆盖的是每条**边**，不是要求所有未选顶点都邻接某个被选顶点；后一种条件属于另一类问题。

### 11.2 独立集与顶点覆盖互为补集（补充证明）

$$
\boxed{S\text{ 是 }G\text{ 的独立集}\iff V\setminus S\text{ 是 }G\text{ 的顶点覆盖}.}
$$

证明只需观察：

- 若 $S$ 内没有边，则每条边至少有一个端点不在 $S$ 中，即被 $V\setminus S$ 覆盖。
- 若 $V\setminus S$ 覆盖所有边，则不可能有一条边的两个端点都在 $S$ 中，因此 $S$ 独立。

若 $\alpha(G)$ 表示最大独立集大小，$\tau(G)$ 表示最小顶点覆盖大小，则

$$
\boxed{\alpha(G)+\tau(G)=n.}
$$

相应地，存在大小至少为 $g$ 的独立集，当且仅当存在大小至多为 $n-g$ 的顶点覆盖。这里参数也必须同步转换，不能沿用相同的阈值。

### 11.3 独立集与补图中的团（补充证明）

补图 $\overline G$ 与 $G$ 具有相同顶点，两个不同顶点之间在 $\overline G$ 中有边，当且仅当它们在 $G$ 中无边。

于是

$$
\boxed{S\text{ 是 }G\text{ 的独立集}\iff S\text{ 是 }\overline G\text{ 的团}.}
$$

注意两种“补”的区别：独立集转顶点覆盖是**对顶点集合取补**；独立集转团是**对整张图取补**，被选顶点集合不变。

### 11.4 一般图与特殊图不能混为一谈

[Lecture 11](lecture11.md) 已介绍树上的最大独立集动态规划。树的不同子树之间没有交叉边，可以按选根／不选根分解；一般图不具备这种结构，不能把树形递推直接照搬过去。

另外，**极大（maximal）不等于最大（maximum）**。在三顶点路径 $a-b-c$ 中，$\{b\}$ 已不能再加入其他顶点，是极大独立集；但最大独立集是 $\{a,c\}$，大小为 2。

## 12. 最长路径为什么必须要求简单？（第 47–48 页）

给定带非负边权的图 $G$、两个指定顶点 $s,t$ 和目标 $g$，要求找一条从 $s$ 到 $t$ 的路径，使

$$
\boxed{\sum_{e\in P}w(e)\ge g,\qquad P\text{ 不重复顶点}.}
$$

后一个条件意味着它是**简单路径（simple path）**。

### 12.1 允许重复经过会改变问题

若允许一般游走，并且存在一个从 $s$ 可达、又可以继续到达 $t$ 的正权闭合路线，就能反复绕行，把总长度无限增大。此时“大于某个阈值”不再表达想要的最长简单路径问题。

非负权不表示每个环权重都严格为正；零权环不会增加长度。但允许重复顶点仍然改变了可行解的定义。

### 12.2 不能简单把边权取负后套最短路

将 $w(e)$ 改为 $-w(e)$，会把正权环变成负权环。常见最短路算法可能因此不适用，或者把问题判为可以无限改善；这与“顶点不能重复”的限制不一致。

**补充：DAG 是特殊情形。** 有向无环图没有绕环问题，可以按拓扑序做最长路 DP：

$$
d(s)=0,\qquad d(v)=-\infty\ (v\ne s),
$$

对每条从已处理顶点 $u$ 出发的边 $u\to v$，执行

$$
d(v)\leftarrow\max\{d(v),d(u)+w(u,v)\}.
$$

拓扑排序和全部转移合计 $O(n+m)$。这说明限制图结构可以重新获得高效算法，不能把 DAG 的结论推广到一般图。

## 13. 背包、编码长度与子集和（第 49–52 页）

### 13.1 本讲是 0/1 背包的阈值版本

给定 $n$ 件物品，每件重量为正整数 $w_i$、价值为非负整数 $v_i$；容量为 $W\ge0$，价值目标为 $g\ge0$。要求找出一个下标集合 $S\subseteq\{1,\ldots,n\}$，使

$$
\boxed{\sum_{i\in S}w_i\le W,\qquad\sum_{i\in S}v_i\ge g.}
$$

每件物品最多选一次，即 $x_i\in\{0,1\}$；不是允许无限重复的完全背包。此处采用标准非负数据假设，以便使用按容量的 DP。

### 13.2 $O(nW)$ 的动态规划回顾

定义

$$
K(i,w)=\text{只使用前 }i\text{ 件物品、总重量不超过 }w\text{ 时的最大价值}.
$$

初始化 $K(0,w)=0$，递推为

$$
K(i,w)=
\begin{cases}
K(i-1,w),&w_i>w,\\[2mm]
\max\{K(i-1,w),\ K(i-1,w-w_i)+v_i\},&w_i\le w.
\end{cases}
$$

两种分支都引用前 $i-1$ 件物品，保证当前物品最多选一次。最后判断

$$
\boxed{K(n,W)\ge g.}
$$

若记录选择决策，还可以回溯出满足条件的物品集合。状态数为 $O(n(W+1))$；通常将非零容量下的时间写为 $O(nW)$。每次加法和比较按常数时间计时得到这个操作数界；严格位复杂度还应计算价值和的位数。

### 13.3 为什么它只是伪多项式时间？

用二进制编码时，容量 $W$ 只占 $\Theta(1+\log(W+1))$ 位，其中常数项包含编码零值所需的开销。类似地，重量和价值的表示长度与它们的对数有关。

取 $W=2^k$，容量的编码长度为 $k+1$，但若按所有容量建表，就有 $2^k+1$ 列。因此

$$
\boxed{O(nW)\text{ 对数值 }W\text{ 是多项式，对二进制输入长度却不一定是多项式}.}
$$

这类运行时间称为**伪多项式时间（pseudo-polynomial time）**。

它不能证明背包存在多项式时间算法；同样，也不能用它证明背包一定需要指数时间。它只是对这个 DP 算法的复杂度分类。

### 13.4 一元编码为什么改变结论？

一元编码用 $W$ 个重复符号表示数值 $W$。例如 12 可以表示为 12 个 `I`。

在 **Unary Knapsack** 中，数值采用一元表示，输入长度 $L$ 至少包含容量所需的 $W$ 个符号，也包含描述 $n$ 件物品的开销。因此 $n,W$ 都被输入长度控制，

$$
nW=O(L^2).
$$

于是同一个按容量的 DP 就是关于这种输入表示的多项式时间算法。

**辨析。** 不能先把二进制实例展开成一元，再声称解决了原问题：二进制数 $2^k$ 展开后需要 $2^k$ 个符号，转换本身可能已经耗费指数时间。

### 13.5 Subset Sum 是背包的特殊情形

令每件物品的价值等于重量，并让价值目标等于容量：

$$
v_i=w_i,\qquad g=W.
$$

背包的两个条件变为

$$
\sum_{i\in S}w_i\le W,\qquad
\sum_{i\in S}w_i\ge W,
$$

因此恰好等价于

$$
\boxed{\sum_{i\in S}w_i=W.}
$$

这就是 **Subset Sum（子集和）**：从给定整数中选出一个子集，使其和恰好为目标 $W$。这里从背包导出的版本使用非负整数；若输入允许负数，下面的 $0,\ldots,W$ 状态范围就不再适用。

**补充例子。** 数列 $(3,5,8,10)$ 的目标为 13 时，$\{3,10\}$ 和 $\{5,8\}$ 都是合法答案。存在一个答案即可，无需找出所有答案。

### 13.6 子集和的布尔 DP（补充）

定义 $B(i,t)$ 表示“能否用前 $i$ 个数凑出恰好 $t$”：

$$
B(0,0)=\mathrm{true},\qquad B(0,t)=\mathrm{false}\quad(t>0),
$$

$$
\boxed{
B(i,t)=B(i-1,t)\lor
\bigl(t\ge w_i\land B(i-1,t-w_i)\bigr).
}
$$

最终答案为 $B(n,W)$。时间同样为 $O(nW)$（按 $W\ge1$ 计），对二进制输入仍是伪多项式。

这也说明：一个问题是另一个问题的特殊情形，不保证它就有多项式算法；必须检查额外结构是否足以带来新的算法。

## 14. 核心结论与易错点速查

### 14.1 看到一个问题，先确认它的版本

| 名称 | 本讲要找的证书／候选解 | 验证要点 |
| --- | --- | --- |
| SAT | 变量赋值 | 每个子句至少有一个真文字 |
| TSP | 城市排列 | 每城一次、闭合返回、费用不超过预算 |
| Euler 迹 | 边的遍历次序 | 相邻边首尾衔接、每条边恰好一次 |
| Hamilton 环 | 顶点循环排列 | 每点一次、相邻点之间有边、闭合 |
| 最小割阈值问题 | 非平凡顶点划分 | 跨割边数不超过预算 |
| 平衡割 | 顶点划分 | 两侧均至少 $n/3$，且跨割边数不超预算 |
| ILP | 非负整数向量 | 全部线性约束成立，并关注证书位数 |
| 3D Matching | $n$ 个允许三元组 | 每个对象恰好出现一次 |
| 独立集 | 顶点子集 | 至少 $g$ 个点，内部无边 |
| 顶点覆盖 | 顶点子集 | 至多 $b$ 个点，覆盖每条边 |
| 团 | 顶点子集 | 至少 $g$ 个点，内部两两相邻 |
| 最长简单路径 | 从 $s$ 到 $t$ 的顶点序列 | 顶点不重复、相邻点有边、权重至少为 $g$ |
| 0/1 背包 | 物品下标子集 | 重量不超 $W$，价值至少为 $g$ |
| Subset Sum | 数字下标子集 | 总和恰好为 $W$ |

表中验证的是给定方案达到阈值或满足定义，不是在一般情况下证明它是全局最优。

### 14.2 算法、公式与转换

| 内容 | 需要记住的结论 |
| --- | --- |
| 2-SAT 建图 | $(\alpha\lor\beta)\mapsto\neg\alpha\to\beta,\ \neg\beta\to\alpha$ |
| 2-SAT 判据 | 任意变量与其否定不在同一 SCC |
| 2-SAT 赋值 | 源到汇拓扑编号下，$x$ 真当且仅当 $r(x)>r(\neg x)$ |
| 2-SAT 时间 | $O(n+m)$ |
| SAT 搜索归约到判定 | 逐个固定变量，至多 $n+1$ 次判定调用 |
| TSP 搜索归约到优化 | 求最优，再与预算比较 |
| TSP 优化归约到搜索 | 非负整数费用下二分预算，$O(1+\log(nD+1))$ 次调用 |
| Euler 迹判据 | 非孤立部分连通，奇度点数为 0 或 2 |
| 无向全局最小割 | 固定 $s$，取 $n-1$ 个最小 $s$–$t$ 割中的最小值 |
| ILP 目标阈值 | $c^Tx\ge g\iff-c^Tx\le-g$，作为新约束并入矩阵 |
| 独立集与覆盖 | $S$ 独立当且仅当 $V\setminus S$ 覆盖全部边 |
| 独立集与团 | $S$ 在 $G$ 中独立当且仅当在 $\overline G$ 中成团 |
| 背包 DP | $O(nW)$ 是关于数值参数的伪多项式界 |
| 背包到子集和特例 | $v_i=w_i,g=W$，两个不等式合为等式 |

### 14.3 易错点与讲义补全

| 容易误记的说法 | 应掌握的表述 |
| --- | --- |
| 候选解指数多，所以任何算法都必须穷举 | MST、最短路等说明可以利用结构绕过穷举 |
| NP 就是非多项式或已经证明很难的问题 | NP 描述 YES 证书可被多项式时间验证，且包含 P |
| 检查一个候选解失败，就证明实例无解 | 只排除了这个候选解 |
| SAT 判定机器回答 YES 时已经输出赋值 | 判定只承诺 YES／NO，恢复赋值需要自归约 |
| 任意搜索问题都自动与其判定版本等价 | 应给出具体归约；本讲详细成立的是 SAT 的构造 |
| 2-SAT 中 $x$ 能到达 $\neg x$ 就无解 | 需要两个方向都可达，即属于同一 SCC |
| SCC 编号越大就一定应取真 | 必须先明确编号是否按源到汇拓扑顺序 |
| Horn 子句至多有两个文字 | 它限制的是正文字数，最多一个 |
| TSP 只要经过全部城市即可 | 还要求每城一次并回到起点，需计入闭环费用 |
| 任意实数费用都能直接二分得到精确最优值 | 有限调用界需要离散性或明确的编码与精度条件 |
| Euler 与 Hamilton 都是“每次只走一次” | Euler 约束边，Hamilton 约束顶点 |
| 第 28 页连通条件必须包含孤立顶点 | 对覆盖全部边的 Euler 问题，只要求非孤立部分连通 |
| 固定一个任意 $t$ 就求得全局最小割 | 讲义算法需要固定 $s$、遍历所有 $t\ne s$ 后取最小值 |
| 平衡割必须两边严格相等 | 本讲只要求两边都至少占 $n/3$ |
| 第 39 页最大化目标应写成 $2x_1+5x_2\le g$ | 应为 $2x_1+5x_2\ge g$，且保留整数限制 |
| ILP 目标阈值冗余，所以可以丢弃 | 只能并入约束矩阵，不能删除其含义 |
| 三维匹配只需把二分匹配再加一层 | 直接拆成两两关系可能产生不允许的三元组 |
| 最大独立集等同于极大独立集 | 极大只保证不能继续加点，未必规模最大 |
| 最长路把边权变负后就变成普通最短路 | 一般图可能出现负环，且简单路径限制仍须满足 |
| $O(nW)$ 显然是多项式时间 | 二进制只需约 $\log W$ 位表示 $W$，所以这是伪多项式 |
| 先展开成一元编码即可高效解决二进制背包 | 展开的输出长度本身可能是指数级 |
| 子集和要求总和不超过 $W$ | 要求恰好等于 $W$ |
